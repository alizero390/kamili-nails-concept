# Kamili Nails — website concept

Concept prototype of a chain website for Kamili Nails (6 studios in Moscow): branch picker, price list, online booking demo with WhatsApp confirmation, reviews block.

Demo only — booking does not send data anywhere. Not the official Kamili Nails website.

## Vivid Nail Salon — website concept

`/vivid/` holds a homepage concept prepared for Vivid Nail Salon & Academy (Martin Place, Sydney): Book / Call / Text buttons, an online booking demo, English / Japanese switch and optimised photos (839 KB versus 7 MB for the current homepage).

Demo only — booking does not send data anywhere. Not the official Vivid Nail Salon website. The page is marked `noindex` so search engines don't list it.
